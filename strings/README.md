# 首頁字串表（帶斷行標記）

`zh.json`、`en.json`、`ja.json` 由字串表產生程式（`design/homepage/build.mjs`）寫出，**不要手改**；要改字或斷行，改產生程式裡的表再重新產生。
網站的元件照這份說明把字串轉成畫面；設計稿 `design/homepage/{zh,en,ja}/index.html` 就是照這裡的規則轉出來的，可以拿來對照。

## 格式

- 一個 JSON 物件：`id → 字串`。**三種語言的 id 完全相同**。
- id 的來源是 `design/homepage/copy.md` 的**文案表**：表頭剛好是 `| id | zh | en | ja | 來源 | 確認 |` 的那些表，每一列一個 id，全部都在（目前 304 個；4-4 加了 `hero.video.pause`、`og.card.line`、`manifest.shortName`；4-f7 加了 `tutorial.lead.noid`；之後加了 `tutorial.apifail`；4-f10 前加了 `changelog.empty`）。
  copy.md 裡其他表頭以 `| id | zh | en | ja |` 開頭的表（例如「最長字串」那一節、表頭是 `| id | zh | en | ja | 為什麼要注意 |`、id 用反引號包著）是說明用的，**不算**。
- 字串拿掉下面的標記之後，跟文案表那一列那個語言的字**一字不差**（產生程式每次都核對，對不上會印警告）。唯一的例外：幾句的「→」「↓」「↺」不在字裡（畫成圖示，見「畫成圖示的符號」）。
- 排過斷行的 id 帶標記；沒排過的是文案表的原字、沒有標記，照一般文字顯示。目前帶標記的：
  `hero.kicker` `hero.title` `hero.sub` `hero.meta.os` `hero.mobile.text` `hero.mobile.bold` `hero.pc` `hero.video.desc` `where.label` `forai.title` `forai.1`～`forai.4` `og.card.line`、
  `how.*`、`features.*`、`privacy.*`、`tutorial.*`、`devices.*`、`req.*`、
  `news.*`（範例的 `news.1.*`～`news.3.*` 除外）、`changelog.*`（範例的 `changelog.10x.*` 除外）、`faq.*`、`author.*`、`final.*`、`foot.*`、`share.fallback`、`root.*`、`404.*`
  （只有一兩個字、不會換行的照原字，例如 `tutorial.chapters`「章節」、`req.price`「免費」、`news.pinned`「置頂」）。
  圖片的替代文字（`*.alt`：`hero.video.alt` `how.1.alt`～`how.3.alt` `forai.outline.alt` `tutorial.poster.alt` `author.photo.alt`）不帶標記，原字放進 `alt`；分享卡的 `og.image.alt` 也不帶標記，放進 `og:image:alt`。
  **章名與摘要（`ch.01.name`～`ch.16.desc`）不帶標記**：那是從教學片的章節資料轉進來的，見「從資料轉進來的字」。
- **代入值**：目前只有三個 —— `%url%`（這一頁的網址，例如 `https://collector.jerromy.com/zh/`）、`%nn%`（教學章號 01～16）、`%章名%`。
  文案表裡寫成 `{url}` `{nn}` `{章名}`，字串表改成 `%…%`，因為 `{` `}` 是標記。**這三個以外的 `%…%` 都算寫錯**；要新增代入值，先改這份說明。

## 標記

| 標記 | 意思 | 轉成 DOM | 樣式（`design/homepage/home.css`） |
|---|---|---|---|
| `«…»` | **斷行單位**：一個完整分句或語意單位。換行只發生在單位之間；寬的時候一行放好幾個單位；單位自己放不下一行時才在裡面換 | `<span class="u">…</span>` | `.u { display: inline-block; max-width: 100%; text-decoration: inherit; }` |
| `{…}` | **整段不換行**：產品名、一個詞、助詞跟著前面的詞、括號跟著旁邊的詞 | `<span class="nw">…</span>` | `.nw { white-space: nowrap; }` |
| `\|` | **可以在這裡換行**（在單位裡：單位放不下一行時才用得到；在所有單位外面：一般的斷點） | `<wbr>` | — |
| `⟨…⟩` | 大標裡被螢光綠括號**夾住的那半句** | `<span class="clamp">…</span>` | `.clamp`；首屏大標裡另外 `display: inline-block` |
| `⟦` | 左括號（空的，不進文字） | `<span class="brk brk--l" aria-hidden="true"></span>` | `.brk`、`.brk--l` |
| `⟧` | 右括號（空的，不進文字） | `<span class="brk brk--r" aria-hidden="true"></span>` | `.brk`、`.brk--r` |
| `⁅…⁆` | **320 寬起整段不換行**（再窄就放不下，只好讓它斷） | `<span class="nw-wide">…</span>` | `@media (min-width: 320px) { .nw-wide { white-space: nowrap; } }` |
| `¦` | **只在 320 寬以下才開的斷點**（放在 `⁅…⁆` 裡面） | `<span class="brk-narrow"></span>` | `@media (max-width: 319px) { .brk-narrow::after { content: "\200B"; } }`（零寬空白；不用 `<wbr>`，因為 `<wbr>` 在 nowrap 裡照樣會斷） |
| `↵` | **分成兩行的大標**：前半句、後半句各自一行（只有 `forai.title`） | 前後兩段各包一個 `<span class="forai__l1">` 與 `<span class="forai__l2">`；`↵` **前面緊接著的所有空白**放在兩個 span 之間（目前只有英文有一個空白；中文、日文沒有，兩個 span 之間什麼都沒有）；`↵` 後面不會有空白 | `.forai__title` 是 grid，兩個 span 各占一列；`.forai__l1` 灰、`.forai__l2` 白 |

**巢狀規則**（解析程式照這幾條寫，不必處理例外）：
- 成對的標記都正確巢狀。各自裡面可以放：
  - `«…»`：`{…}`、`⟨…⟩`、`⁅…⁆`、`|`、`«…»`
  - `{…}`：`⟨…⟩`、`⟦` `⟧`（例：`{讀者是 ⟨⟦AI⟧⟩。}`）
  - `⟨…⟩`：`{…}`、`⁅…⁆`、`|`、`⟦` `⟧`（例：中文 `⟨{⟦AI 讀得懂的}|{素材庫⟧}⟩`；日文 `⟨{⟦AI} が読める⁅素材¦{ライブラリに⟧}⁆⟩`；`forai.title` 的 `⟦` `⟧` 直接在 `⟨` 裡：`⟨⟦AI⟧⟩`）
  - `⁅…⁆`：`{…}`、`¦`
- `{…}` 不會套 `{…}`；`«…»` 不會出現在 `{…}` 裡面；`↵` 只出現在最外層（不在任何成對標記裡）。
- **`«` 最多三層**（數的是 `«` 的巢狀深度；目前只有日文 `req.lang` 是三層，其餘最多兩層）。
- `|` 可以出現在所有單位外面（例：中文 `hero.mobile.bold` `這是|電腦版 {Chrome 的}|免費擴充`、`where.label` `可以在|這些地方用`）。
- 標記字元不會以字面意義出現在字裡（文案表全查過沒有 `«»⟨⟩⟦⟧⁅⁆¦↵{}|%`；`%` 只用在代入值）。

**一句一個外層單位**：說明文字（區塊說明、步驟與卡片的一句、規格表內容、「為 AI 做的」四點）裡，到句末（。！？／英文 `.` `!` `?` `:`）為止的幾個分句單位，外面再包一層 `«…»`。
外層是行內區塊：整句放得下一行，就整句換到新的一行（不會一句話從上一句的行尾開始、也不會在放得下的時候被拆）；放不下才在裡面那幾個分句之間換。
例：日文 `privacy.lead` 是 `««作者があなたのデータを»«受け取ることはできません。»»«受け取る場所が存在しないからです。»`。轉成 DOM 照下面的順序，巢狀的 `«` `»` 一樣轉成 `<span class="u">`。

**轉換順序**（照這個順序做字串取代，就會得到設計稿裡的 HTML）：
1. `⟦` `⟧` → 括號 span
2. `⟨` → `<span class="clamp">`，`⟩` → `</span>`
3. `⁅` → `<span class="nw-wide">`，`⁆` → `</span>`，`¦` → `<span class="brk-narrow"></span>`
4. `«` → `<span class="u">`，`»` → `</span>`
5. `{…}` → `<span class="nw">…</span>`（不巢狀，可以用 `/\{([^{}]*)\}/g`）
6. `|` → `<wbr>`
7. `↵`：在第 1～6 步之前先用它把字串切成兩段，各自轉換後放進兩個 span。
8. 代入值：最後才換（值裡如果有標記字元也不會被誤轉）。

用 React 的話，建議寫成一個小的解析器把字串轉成元素樹（不要用 `dangerouslySetInnerHTML`），結果要跟上面的 HTML 結構一樣。

## 語言另外要設的

- 中文：版型裡的字所在的區塊設 `word-break: keep-all`（設計稿是 `:is(.nav, .menu, main, .touch, .states):lang(zh-Hant)`）—— 只會在 `<wbr>`、空白、標點處斷，詞不會被瀏覽器從中間切開。
- 日文：`word-break: auto-phrase`（照詞組斷，設在 `:root:lang(ja)`）。
- 英文：一般斷行。
- 說明文字一行最寬 `--measure: 25em`（約 25 個中文字）。

## 使用者自己寫的內容（不帶標記）

這幾類是網站管理者在 `content/` 裡自己寫的（文案表裡是範例），**字串表裡沒有標記，也不要求寫標記**：
- `bulletin.text`（公告條的標題，＝最新一則公告的標題）
- `news.1.title` `news.1.body` … `news.3.body`（最新公告的每一則）
- `changelog.105.1` … `changelog.104.6` 這類「一版裡的一條」（更新紀錄）
- 社群連結（三語共用的一支連結檔：一行一個「代號 · 網址」；名字照字串表的 `social.<代號>`）

它們照寫的人的字與換行顯示（公告內文的元素設 `white-space: pre-line`；讀進來的公告內文行與行之間是 `\n`、段落是 `\n\n`），字本身一個都不改。
產生網頁時用網站的 `bindTail(text, lang, { tail })`（`lib/bind-tail.js`）把一段話變成 HTML，只做兩件事，其他字一律跳脫（`& < > " '`），不轉任何標記：

1. **防孤字**：只動**最後一個非空行**（不從上一行借字；結尾的空白與換行留在外面）。
   - 中文、日文：最後三個字包進 `<span class="nw">`。「字」是書寫字位（`Intl.Segmenter` 的 grapheme），漢字、假名、標點、英數字、空白都算一個，emoji 與組合字不會被切半；不足三個字就整行都包。
   - 英文：最後兩個字包進 `<span class="nw">`（以空白切字，標點、連字號、撇號、網址都跟著那個字；兩個字中間的空白在 span 裡）。**長度上限 20 個字元**（以 Unicode 碼位算）：兩個字合計（含中間的空白）超過 20 就只包最後一個字；最後一個字本身超過 20 就不包。中文頁裡的英文照中文的規則。
   - 尾端圖示（`tail`，例如公告條的箭頭 `<span class="i i--arrow"></span>`）放在那個 span 的裡面、結尾；不包 span 時接在最後一個字後面。
2. **只有中文：詞界插 `<wbr>`**。用 `Intl.Segmenter`（`zh-Hant`，`granularity: 'word'`）切詞，只插在同一行裡**相鄰兩段都是詞（`isWordLike`）**的地方：
   - 標點與空白的前後都不插；不連續兩個；不在每一行的頭尾；不在綁住的 `<span class="nw">` 裡面（詞界剛好在 span 開頭時，`<wbr>` 放在 span 前面：`暫時<wbr><span class="nw">不能用</span>`）。
   - **短引號裡不插**：`「…」`、`『…』`、`“…”` 一對裡面 12 個字以內（以碼位算，不算引號本身）整段不插，13 個以上照插；沒關起來的引號不算。
   - **日文不插、英文不插**。日文靠樣式 `word-break: auto-phrase`（元素要有 `lang="ja"`，頁面的 `<html lang="ja">` 就是）；英文在空白處斷。
   - 拿掉所有 `<wbr>`，結果跟不插時逐字相同。

**樣式**：中文的使用者內容（公告條的標題、公告的標題與內文、更新紀錄的每一條）設 `word-break: keep-all`（只在 `<wbr>`、空白、標點處斷），並加 `overflow-wrap: anywhere`（一長串沒有斷點的中文才不會橫向捲動；flex 子項裡 `break-word` 兜不住）。日文 `auto-phrase`，英文一般斷行。
**例**（實際內容，`|` 是 `<wbr>`、`[…]` 是 `<span class="nw">`）：中文公告標題「ChatGPT 改版：「存這則」「存這頁」暫時|[不能用]」；中文內文「其他|網頁|與 Claude、Perplexity 不受|影響。修正|跟 1.0.5 一[起出。]」；日文「…一時的に使え[ません]」（沒有 `<wbr>`）。
**已知的取捨**（接受）：自動斷詞會誤切（例：「收集｜器」），`keep-all` 時行只會在這些位置斷；產品名、數字與單位沒有另外綁（規格書 §7：使用者寫的內容詞偶爾被拆開可以接受）；`Intl.Segmenter` 的切法跟著 ICU 版本走，產生網頁時算好寫進 HTML。

### 公告（最新公告那一區）

- 一則一張卡片：日期（`<time datetime>`，等寬）、類別（使用者自由寫的字，用小標的螢光綠等寬字）、有「置頂」的加一個 `news.pinned` 標籤（圖示 `ui-push-pin`）、標題（`h3`）、內文、有連結的放 `news.more`（箭頭圖示），整張卡都能按。
- 照內容檔的順序，前三則一排（桌機三欄、平板與手機一欄）；第四則起收在 `<details>`，`<summary>` 是 `news.older`（加 `ui-caret-down`，打開時轉 180°）。寫壞的那一則照樣佔它的位置（見「這一條讀不到」）。
- 一則都沒有：只顯示一句 `news.empty`，區塊照留（導覽列連得到）。

### 更新紀錄的類型標記

內容檔一條寫成「`- 修好：…`」，讀進來時第一個冒號（全形「：」或半形「:」）前面的字是 kind、後面是內文。**沒有前綴的整句也可能被切出一個 kind**（例：「拿掉選取文字後浮出的按鈕：選起來之後按右鍵…」的 kind 會是「拿掉選取文字後浮出的按鈕」）。所以：

- **只有在這個語言的類型詞清單裡的 kind 才畫成類型標記**（左邊一欄、螢光綠等寬字；完全相同，英文不分大小寫；清單裡的詞都在 6 個全形字／12 個字元以內）：
  - 中文：修好、修正、新增、改善、改進、調整、變更、拿掉、移除、更新、安全性、效能
  - 英文：Fixed、Fix、New、Added、Improved、Changed、Removed、Updated、Security、Performance
  - 日文：修正、不具合修正、新機能、追加、改善、改良、変更、削除、廃止、更新、セキュリティ、性能
- **標記上的字照內容檔寫的顯示**（寫「Fix」就顯示 Fix，不換成字串表的字）。`changelog.fixed`、`changelog.added` 兩個 id 不上畫面：它們是三語內容檔建議的寫法（中「修好／新增」、英「Fixed／New」、日「修正／新機能」，跟內容檔檔頭的範例同一組）。
- 其他情形（不在清單裡）：**整句當內文**，用讀進來的原句 `raw`（那一行去掉開頭的「-」與頭尾空白，冒號照使用者寫的），左邊那一欄空著，內文照樣對齊右欄。
- 沒有冒號的一條：kind 是空的，整句當內文。
- 例（1.0.4 的實際內容）：「修好：縮圖一多，格子會疊在一起」→ 標記「修好」＋內文「縮圖一多，格子會疊在一起」；「拿掉選取文字後浮出的按鈕：選起來之後按右鍵…」→ 沒有標記，整句當內文。
- 清單要加詞就加在這裡與產生程式的 `KINDS`，兩邊同一份。
- 每一版：版本號（`h3`，等寬細字）、日期（`<time datetime>`）；最上面那一個好的版本加 `changelog.latest` 標籤。前兩版攤開，第三版起收在 `<details>`（`changelog.older`）。
- **沒有可列的版本**（內容檔裡一版都沒有，或全是不列的版本，例如只有 1.0.3）：同公告，只顯示一句 `changelog.empty`（`<p class="empty">`，樣式同 `news.empty`），區塊照留（導覽列與頁尾連得到）。每一版都寫壞時照舊是整區一個虛線框（`state.unreadable.section`）。

### 這一條讀不到

公告、更新紀錄、社群連結寫壞的那一條（讀進來是 `{ ok: false, … }`），在它自己的位置畫 `state.unreadable`，**不顯示原因**（原因給檢查內容的命令與部署時的警告）：

| 哪裡 | 壞的是 | 畫成 |
|---|---|---|
| 公告 | 一則 | 跟卡片一樣大的虛線卡（`.card.card--bad`），裡面圖示 `ui-warning-circle`＋字 |
| 更新紀錄 | 一條 | 那一行一個虛線框（`.bad.bad--inline`，從左邊類型標記那一欄開始），同一版其他條照常 |
| 更新紀錄 | 版本那一行（整版） | 整版一個虛線框（`.bad.bad--section`） |
| 社群連結 | 一條 | **只在作者與社群那一區**畫一個 44 高的虛線框（`.bad.bad--social`）；選單與頁尾直接跳過 |
| 公告、更新紀錄 | 整支讀不到、或每一條都寫壞 | 整區一個虛線框，字用 `state.unreadable.section` |

虛線框是「這一格缺了一塊」的意思；不用錯誤的粉紅（寫壞的是網站管理者，不是看的人做錯事）。

### 社群連結

- 代號有圖示檔（`icons/<代號>.svg`）：44×44 的圓形圖示鈕，名字（`social.<代號>`）放 `aria-label` 與 `title`。
- **代號沒有圖示檔**（新加了代號、圖示還沒放）：用代號當名字的文字膠囊（`.iconbtn--text`，一樣 44 高、等寬字），字串表裡沒有那個代號的名字時就顯示代號本身。

## 從資料轉進來的字（章名、摘要）

教學影片區的章名與摘要是產生網頁時從教學片的章節資料轉進來的，教學片重算就整份換掉 —— 沒辦法一句一句人工排，所以用**規則**，產生網頁時自動做；字本身不改。

**1. 綁住的範圍**。在原字上找出這幾種範圍：
| # | 什麼 | 中文、日文 | 英文 |
|---|---|---|---|

**合併**：範圍重疊的合併成一段；**剛好相接**的分開兩段，只有後一段以收尾的標點開頭（`」』）”’、。，；：！？`）時才合併（兩段 nowrap 中間瀏覽器不套避頭規則，「」」會跑到行首）。

**寬度分級**（綁住的那一段太寬時會凸出框外，所以照寬度決定從多寬的螢幕起才不換行）：
- 估寬：全形字算 1、拉丁字母與數字算 0.55、空白與其他半形字元算 0.3，加總。
- 摘要：≤14 包 `<span class="nw">`（一律不換行）；≤17 包 `<span class="nw-320">`（螢幕 320 起不換行）；≤20 包 `<span class="nw-360">`（360 起不換行）；再寬就**不包**（照一般規則斷）。
- 章名那一欄比摘要窄，估寬先加 5 再照上面分級。
- 樣式：`.nw { white-space: nowrap; }`、`@media (min-width: 320px) { .nw-320 { white-space: nowrap; } }`、`@media (min-width: 360px) { .nw-360 { white-space: nowrap; } }`。
- **⑤′ 降級時照樣綁住助詞那一小段**：一段綁住的範圍要降級（`nw-320`、`nw-360`）或不包的時候，它的結尾若是 ⑤ 的形狀（收引號＋助詞，或英數字＋空白＋助詞），
  結尾那一小段另外包一層 `<span class="nw">`：收引號＋助詞那種，從**收引號前面那個詞**（`Intl.Segmenter` 的 ja）的開頭起；英數字那種，從那一串英數字的開頭起。
  那一小段估寬也要 ≤14（章名 +5 之後）才包。外層照原本的級別包（例：`<span class="nw-360">「インスピレーション・<span class="nw">コレクター」を</span></span>`）—— 窄的時候名字可以在「・」之後換行，但「を」不會跑到行首。
- 這幾個數字是照摘要那一欄的寬量的：280 寬約 14 個全形字、320 約 17、360 約 20；窄的時候（播放器容器 < 480px）摘要不縮排到章名那一欄（左右內距都是 20px）。

**2. 斷行單位**（`<span class="u">`，行內區塊；只用在摘要）：
- 先切句：中日文在 `。！？；` 後面，英文在 `. ! ? ; :` 後面（後面接空白的才算；那個空白放在兩個單位之間）。每一句一個單位。
  **中日文不到 5 個字的句子併回前一句**（4-4，4-f7 設計審查：第 04 章「…」；一段一筆。」的「一段一筆。」原本自己一行；同下一條分句的規則，往上一層、方向往前）。
- 中日文的句子再切分句：中文在 `，：` 後面、日文在 `、，：` 後面（中文的「、」是列舉，不切）；**不到 5 個字的分句併進下一個**。一句有兩個以上分句時，分句各自一個單位、外面那一句也是一個單位（巢狀）。英文不切分句。
- 切的位置落在 1. 的綁住範圍裡面就不切。

**3. 每個單位自己的尾巴也綁住**（只用在摘要）：中日文每一個分句（或沒切分句的整句）**不到 10 個字的整段綁住**，10 字以上的從最後往前數到 **5 個全形字寬**（4-4 改：原本數 5 個「字」，一個拉丁字母也算一個字 —— 「原檔存進 assets/；」只綁到「assets/；」（實際 4.6 個字寬），換行時那一行只剩它）。寬照 `est()`：全形字 1、拉丁字母與數字 0.55、其他半形字 0.3，標點 `，。、；：！？「」『』（）・` 與空白不算；數到夠寬再往前挪到那個詞的開頭（同 ④ 的挪法）；**日文挪完剛好落在助詞（`をにがはでとのもへや`，Segmenter 把它切成自己一個詞）時，再往前併一個詞**（不然助詞會跑到行首）。綁到結尾；英文每一句最後兩個字。單位放不下一行、只好在裡面換時，最後一行不會只剩三四個字。

**4. 樣式**：中文摘要與章名 `word-break: keep-all`（只在空白、標點、單位之間斷；放不下時由 `overflow-wrap: break-word` 兜底）；中文摘要在綁住範圍以外的每個「`「`」前面補一個 `<wbr>`（keep-all 時「搜尋「靈感收集器」」的「前面不給斷）。日文 `auto-phrase`。英文一般斷行。

**5. 章名**只做 1.（綁住），不切單位：章名在 grid 裡跟章號、時間對齊基線，切成行內區塊會讓基線跑到最後一行。

**6. 怎麼驗**：三件事一起量 —— 短行、過長、行首標點、單獨一個標點的行；「詞被拆開」（每一個斷行點，落在 產品名清單／「」12 字內的引號／數字＋單位／`Intl.Segmenter` 的詞 中間就算一處）；綁住的那一段有沒有凸出框外。量到的（章名與摘要三語 × 280～1440 共 14 種寬度）：320 寬起短行、行首標點、孤標點 0，360 寬起詞被拆開 0，凸出框外 0；320 寬只剩日文第 01 章的名字在「・」之後換行（⑤′ 的取捨：換來「を」不在行首）；280 寬：章名三個換兩行時第二行短（「清除資料」「保存」「topics」），詞被拆開 3 處（「インスピレーション・｜コレクター」「AI に｜渡しましょう」「搜｜尋」：那一段比 280 寬的一行還長，只能斷）。
注意：Node 與瀏覽器的 `Intl.Segmenter` 都是 ICU，但版本可能不同，少數詞界會不一樣；網站在產生網頁時（Node）算好寫進 HTML，瀏覽器不再算。

## 「/」與 404（一頁三種語言）

這兩頁整頁標英文（`lang="en"`），三種語言各取自己那一欄的字、各標自己的語言（`zh-Hant`、`en`、`ja`）：`root.name`（大標的三行）、`root.lead` 與 `root.pick`（三欄，各一顆按鈕連到自己的語言頁）；404 是 `404.title`（大標三行）、`404.body` 與 `404.home`。
中文那幾段設 `word-break: keep-all`，日文那幾段換日文字型並設 `auto-phrase`（整頁是英文，不會自己換）。

## 畫成圖示的符號

文案表裡寫成文字的幾個符號，畫面上畫成圖示，**字串表裡沒有那個符號**；產生程式核對時把文案表那一句開頭的「↺ 」、結尾的「 →」「 ↓」拿掉再比：

| id | 符號 | 圖示 | 放哪裡 |
|---|---|---|---|
| `hero.pc`、`features.more`、`privacy.link`、`tutorial.next`、`tutorial.again`、`news.more`、`author.blog`、`final.pc` | → | `ui-arrow-right` | 最後一個 `{…}` 的裡面、結尾 —— 跟最後一個詞一起換行。`tutorial.next` 的字沒有 `{…}`（後半是章名）：放進章名結尾綁住的那一段（資料規則 ④）的裡面、結尾 |
| `tutorial.showAll` | ↓ | `ui-caret-down`（展開時轉 180°） | 字後面，按鈕裡另一個元素 |
| `tutorial.replay` | ↺ | `ui-replay` | 字前面，按鈕裡另一個元素 |

`tutorial.next`、`tutorial.done` 裡的 `%章名%` 換成那一章的章名（資料，照上一節加安全網）。

## 特別的 id

- `hero.mobile.text`：第一個單位 `«…»` 開頭那一段，正好等於 `hero.mobile.bold` 的字 —— 那一段要包 `<b>`（設計稿是 `«<b>這是…免費擴充</b>，»…`）。做法：在第一個 `«` 後面找到 `hero.mobile.bold` 的字（帶它自己的標記）原樣出現的地方，包上 `<b>`。
- `final.title`：跟首屏大標一樣，後半句被螢光綠括號夾住（`⟨⟦…⟧⟩`），`.clamp` 設 `display: inline-block`。
- `final.cta`、`final.share`、`final.mail`、`final.pc`：跟首屏同一個字（`hero.cta`、`hero.share`、`hero.mail`、`hero.pc`）；`final.mobile.lead` 是最後一區手指框的說明（首屏用 `hero.mobile.text`）。
- `share.fallback`：手指框裡「分享這個網址」用不了時（關掉 JS、或 App 裡的瀏覽器分享選單與剪貼簿都不能用），換成這一句＋直接顯示這一頁的網址（等寬字，點一下全選、長按複製）。
- `hero.title`（4-4 改了中英的標法）：中文 `{把網頁收成} ⟨{⟦AI} {讀得懂的素材庫⟧}⟩` —— 「AI」後面那個空白是 360 以下才用的斷點：那時 `.clamp` 要設 `display: inline`（`@media (max-width: 359px) { :lang(zh-Hant) .hero__title .clamp { display: inline } }`），「[AI」跟著前半句、「讀得懂的素材庫]」一行；360 起 `.clamp` 照舊 `inline-block`，整半句換到下一行。英文 `Turn the {web into} ⟨…⟩`：280 寬時「into」不會單獨一行。
- `tutorial.apifail`：YouTube 的播放器程式載不到（或 8 秒還沒好）時蓋在影片框上的一句（`<p class="player__fail" role="status">`，放在播放鈕前面）；640 起在框的左上角，手機整個框蓋一層不透明的底、字放中間（`home.css` 的 `.player__fail`、`動態.md` 09 表）。
- `hero.video.play`／`hero.video.pause`：宣傳片那一顆鈕的名字（`aria-label`），跟著狀態換 —— 還沒播、已暫停是 `hero.video.play`，播放中是 `hero.video.pause`（同一顆鈕，見 `notes/4-4.md`）。
- `manifest.shortName`：`site.webmanifest` 的 `short_name`（Android 主畫面圖示底下的名字，各 ≤ 12 字元）；`name` 用 `nav.brand`。
- `og.card.line`：分享卡大標底下那一行（只在分享卡的圖上，不在網頁上）；分享卡的大標用 `hero.title`、名稱用 `nav.brand`。
- `hero.pc`：文案表的字結尾有「→」，這裡沒有 —— 箭頭畫成圖示 `<span class="i i--arrow"></span>`，放在**最後一個 `{…}` 的裡面、結尾**（箭頭才會跟最後一個詞一起換行，不會單獨掉到下一行）。

## 還沒有影片 ID 的時候

教學片還沒上 YouTube 時，網站照「有沒有影片 ID」切換（ID 寫在網站的資料檔，一個語言一個）：
- 大標用 `tutorial.title.noid`（中「16 章使用說明」），不用 `tutorial.title`（「16 章教學影片」會讓人以為能按）。
- 一句 `tutorial.noid.note`（中「影片上傳後，就能在這裡播。」）放在影片框外面、框的下一列（手機在框底下；640 起疊回框的左下角，見 `home.css` 的 `.player__note`）；不放播放鈕、不放「在 YouTube 上看」。
- 章節清單與摘要照放，每一列是摘要的開關（`<summary>`）。「能收什麼」卡片上的「看教學 NN」本來就連到 `#ch-NN`，有影片時由程式接管去播。
- 「支援裝置」✓ 卡給讀屏的字是 `devices.yes`（「可以用」），✕ 卡是 `devices.no`（「不行」），都包在 `<span class="sr">`。
